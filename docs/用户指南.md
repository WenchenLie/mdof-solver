# mdof-solver 中文用户指南

## 一、程序概览

### 1.1 主要作用

`mdof-solver` 用于求解小型和中型非线性多自由度体系的动力方程：

\[
M\ddot u(t)+C\dot u(t)+f_{\mathrm{int}}(u,\text{材料历史})=p(t).
\]

用户负责准备质量矩阵 `M`、阻尼矩阵 `C`、刚度表达式、等步长节点荷载样本和初始条件。程序负责：

- 根据刚度表达式建立弹性连接和非线性单轴材料连接。
- 管理每条连接相互独立的材料试算状态和提交状态。
- 使用 Newmark、HHT 或中心差分法推进时程。
- 使用 Linear、Newton、NewtonLineSearch 或 KrylovNewton 求解每个时间步。
- 使用力、位移增量或能量收敛检验判断迭代是否完成。
- 在不收敛时自动缩小步长并切换候选算法。
- 计算初始刚度对应的模态信息。
- 按需记录节点位移、速度、加速度、单元内力和单元变形。

程序不读取地震动文件，也不自动把地面加速度转换成惯性荷载。若采用相对位移方程，用户应先计算：

\[
p(t)=-M\Gamma\ddot u_g(t),
\]

其中 `Γ` 为影响向量，`ü_g` 为地面加速度。程序输出的加速度与用户输入的动力方程采用相同坐标系；绝对加速度需要用户自行与地面加速度合成。

### 1.2 模型组织方式

一次分析由以下对象组成：

```text
质量矩阵 + 阻尼矩阵 + 刚度表达式 + 荷载
                       ↓
                     System
                       ↓
积分器 + 候选算法 + 收敛检验 + 自适应参数
                       ↓
               TransientAnalysis
                       ↓
                  Recorder
                       ↓
                 AnalysisResult
```

刚度矩阵既可以包含普通数值，也可以包含 `Elastic`、`Steel01` 和 `ModTakeda` 材料模板。数值项直接参与线性恢复力计算；材料模板会被编译为独立的单元运行实例。

用户不需要定义接地自由度。程序根据刚度矩阵中的材料系数识别以下内部变形关系：

- 对地连接：`q = u[i]`。
- 两自由度连接：`q = u[j] - u[i]`。

这些关系用于材料内力计算，也可以通过 `ele_defo` 输出。`System.eles` 提供每条连接的编号、材料 tag、权重、自由度和变形系数。

### 1.3 安装、导入与运行

项目要求 Python 3.14，并使用 uv 管理环境：

```bash
uv sync --group dev
uv run python main.py
uv run python examples/basic_nonlinear.py
uv run pytest
```

推荐按模块导入：

```python
from mdof_solver.algorithms import (
    KrylovNewton, Linear, Newton, NewtonLineSearch, SolutionAlgorithm,
)
from mdof_solver.analysis import TransientAnalysis
from mdof_solver.convergence import (
    ConvergenceTest, EnergyIncr, NormDispIncr, NormUnbalance,
)
from mdof_solver.exceptions import AnalysisFailure
from mdof_solver.integrators import CentralDifference, HHT, Newmark
from mdof_solver.loading import LoadHistory
from mdof_solver.materials import (
    Elastic, ModTakeda, Steel01, StiffnessExpression, UniaxialMaterial,
)
from mdof_solver.matrices import DampingMatrix, MassMatrix, StiffnessMatrix
from mdof_solver.model import ElementInfo, ModalResult, System
from mdof_solver.recording import AnalysisResult, Peak, Recorder
```

自由度从 `0` 开始编号。所有输入必须使用一致单位制。例如采用 `N-m-s` 时，质量、刚度、阻尼、位移和荷载都必须与该单位制一致。

项目根目录的 [main.py](../main.py) 是完整的四自由度非线性算例。下一章的十个小节与该文件中编号为 1 至 10 的代码块逐一对应。

## 二、按十个步骤建立并运行模型

### 2.1 地震动

对应 `main.py` 的第 1 个代码块：

```python
dt = 0.01
duration = 5.0
sample_count = round(duration / dt) + 1
sample_index = np.arange(sample_count)
time = sample_index * dt
ground_acceleration = (
    4.0 * np.sin(2.0 * np.pi * 1.2 * time) * np.exp(-0.35 * time)
)
```

这里的关键变量类型为：

| 变量 | 类型 | 含义 |
|---|---|---|
| `dt` | `float` | 相邻地震动样本之间的时间间隔，同时作为本例的初始分析步长。必须大于 `0`。 |
| `duration` | `float` | 输入记录总时长。 |
| `sample_count` | `int` | 样本数量；包括初始时刻，因此通常为 `duration/dt + 1`。 |
| `ground_acceleration` | `numpy.ndarray`，形状 `(n_step,)` | 等步长地面加速度样本。每个值对应 `t0 + i*dt`。 |

`time` 在本例中只用于生成演示波形，不传给 `LoadHistory`。实际使用时，可以用 NumPy 或其他库读取地震动文件，但应整理为一维、有限、等步长的数组。

分析初始步长可以小于荷载采样步长。程序会对相邻荷载样本进行线性插值。中心差分法除外：它采用固定计算步长，分析终点必须落在计算网格上。

### 2.2 质量矩阵

对应 `main.py` 的第 2 个代码块：

```python
masses = np.array([2.0, 1.8, 1.5, 1.2])
mass = MassMatrix(np.diag(masses))
```

构造接口：

```python
MassMatrix(values: numpy.typing.ArrayLike) -> MassMatrix
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `values` | `ArrayLike` | 质量矩阵。必须是有限、对称、正定的二维方阵；允许包含非对角质量项。 |

常用属性和运算：

```python
mass.values: numpy.ndarray
mass.shape: tuple[int, int]

mass_a + mass_b -> MassMatrix
mass_a - mass_b -> MassMatrix
factor * mass -> MassMatrix
```

`values` 是求解器使用的浮点 NumPy 数组。正定要求意味着模型中不能保留零质量自由度；固定、从属或其他约束自由度应在构造矩阵前由用户消除。

### 2.3 荷载时程

对应 `main.py` 的第 3 个代码块：

```python
influence = np.ones(4)
force_pattern = mass.values @ influence
load_samples = -ground_acceleration[:, None] * force_pattern[None, :]
load = LoadHistory(load_samples, dt=dt)
```

等步长数组接口：

```python
LoadHistory(
    samples_or_function: numpy.typing.ArrayLike,
    *,
    dt: float,
    t0: float = 0.0,
) -> LoadHistory
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `samples_or_function` | `ArrayLike`，形状 `(n_time, n_dof)` | 节点荷载样本。每行是一个时刻的完整荷载向量，每列对应一个自由度；至少需要两个时刻。 |
| `dt` | `float` | 荷载采样间隔，必须大于 `0`。 |
| `t0` | `float` | 第一个荷载样本的时刻，默认 `0.0`。 |

主要属性和调用接口：

```python
load.dt: float
load.t_min: float
load.t_max: float
load.size: int
load(time: float) -> numpy.ndarray
```

`load(time)` 返回给定时刻的节点荷载向量。查询时刻位于两个样本之间时采用线性插值，超出 `[t_min, t_max]` 会报错。

也可以直接提供连续时间函数：

```python
LoadHistory(
    samples_or_function: Callable[[float], ArrayLike],
    *,
    t_min: float,
    t_max: float,
    size: int,
) -> LoadHistory
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `samples_or_function` | `Callable[[float], ArrayLike]` | 输入时刻并返回节点荷载向量的函数。 |
| `t_min` | `float` | 函数荷载允许查询的起始时刻。 |
| `t_max` | `float` | 函数荷载允许查询的终止时刻，必须大于 `t_min`。 |
| `size` | `int` | 荷载向量长度，必须等于模型自由度数。 |

两个自由度数相同且有效时间范围相交的荷载对象可以相加：

```python
combined_load = load_a + load_b
```

结果的有效时间范围是两个输入范围的交集。

### 2.4 材料与刚度

对应 `main.py` 的第 4 个代码块：

```python
k1 = Steel01(tag=1, Fy=6.0, k=320.0, b=0.02)
k2 = Steel01(tag=2, Fy=5.0, k=280.0, b=0.015)
k3 = Elastic(tag=3, k=240.0)
k4 = 180.0
```

材料对象放入刚度矩阵时代表规则模板。体系建立后，每条识别出的连接会获得独立材料副本，因此同一模板出现在不同变形映射中时不会共享力和历史状态。本算例中，`k1` 和 `k2` 是参数不同的双线性材料，`k3` 是可独立记录的弹性材料，`k4` 是直接参与整体刚度计算的普通数值。

#### Elastic

```python
Elastic(tag: int, k: float) -> Elastic
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `tag` | `int` | 材料模板的唯一整数编号。布尔值、浮点数和字符串均不接受。 |
| `k` | `float` | 弹性刚度，必须大于 `0`。 |

#### Steel01

```python
Steel01(tag: int, Fy: float, k: float, b: float) -> Steel01
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `tag` | `int` | 材料模板的唯一整数编号。 |
| `Fy` | `float` | 正向屈服力的绝对值，必须大于 `0`；负向屈服力为 `-Fy`。 |
| `k` | `float` | 初始弹性刚度，必须大于 `0`；屈服变形为 `Fy/k`。 |
| `b` | `float` | 屈服后刚度与初始刚度之比；屈服后分支刚度为 `b*k`。 |

`Steel01.getTangent()` 在弹性活动分支返回 `k`，在塑性活动分支返回 `b*k`。屈服折点处导数不唯一，当前返回弹性侧刚度。

#### ModTakeda

```python
ModTakeda(
    tag: int,
    Fy: float,
    k0: float,
    r: float,
    alpha: float,
    beta: float,
) -> ModTakeda
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `tag` | `int` | 材料模板的唯一整数编号。 |
| `Fy` | `float` | 骨架曲线屈服力的绝对值，必须大于 `0`。 |
| `k0` | `float` | 初始刚度，必须大于 `0`；屈服变形为 `Fy/k0`。 |
| `r` | `float` | 屈服后刚度比；骨架屈服后刚度为 `r*k0`。 |
| `alpha` | `float` | 卸载刚度退化指数，必须不小于 `0`。 |
| `beta` | `float` | 再加载目标点相对历史峰值的退化参数，必须不小于 `0`。 |

`ModTakeda.getTangent()` 返回最近提交点到当前试算点的增量割线。若一个迭代增量跨越屈服点、卸载转折点或再加载目标点，该割线可能不同于试算点所在分支的局部导数。这种情况下 Newton 法通常仍可通过反复迭代达到平衡，但不保证一致切线 Newton 的二次收敛速度。

同一 `System` 中，不同模板必须使用不同 tag。同一个模板对象可以在刚度矩阵的多个相关位置重复出现，因为这些位置共同描述同一类材料贡献。

### 2.5 刚度矩阵

对应 `main.py` 的第 5 个代码块：

```python
stiffness = StiffnessMatrix([
    [k1 + k2, -k2, 0.0, 0.0],
    [-k2, k2 + k3, -k3, 0.0],
    [0.0, -k3, k3 + k4, -k4],
    [0.0, 0.0, -k4, k4],
])
```

构造接口：

```python
StiffnessMatrix(
    values: Iterable[
        Iterable[float | UniaxialMaterial | StiffnessExpression]
    ]
) -> StiffnessMatrix
```

`values` 必须构成非空方阵。每个位置可以是：

| 值的类型 | 含义 |
|---|---|
| `float` 或其他实数 | 直接参与 `K_numeric @ u` 的普通弹性刚度矩阵项，不生成可单独记录的单元。 |
| `UniaxialMaterial` | 系数为 `1` 的材料模板项。 |
| `StiffnessExpression` | 材料模板、数值及其线性组合，例如 `2*k1 + k2`。通常由运算符自动生成。 |

支持以下运算：

```python
k1 + k2 -> StiffnessExpression
2.0 * k1 -> StiffnessExpression
-k1 -> StiffnessExpression

stiffness_a + stiffness_b -> StiffnessMatrix
stiffness_a - stiffness_b -> StiffnessMatrix
factor * stiffness -> StiffnessMatrix
```

每种材料模板对应的系数矩阵必须满足：

- 对称。
- 非对角项不大于零。
- 每一行的行和不小于零。

程序由非对角项建立 `u[j]-u[i]` 映射，由正的行和建立 `u[i]` 映射。材料权重只缩放材料返回的力和切线，不缩放输入变形。

例如：

```python
mat = Steel01(tag=10, Fy=10.0, k=100.0, b=0.02)
stiffness = StiffnessMatrix([
    [2 * mat, -mat],
    [-mat, mat],
])
```

该矩阵生成两条独立连接：一条使用 `u[0]`，另一条使用 `u[1]-u[0]`。两条连接各自拥有材料历史。一条屈服不会直接改变另一条的状态。

若希望分别输出两根参数相同的并联单元，应创建两个具有不同 tag 的模板对象。若对同一个模板、同一个映射重复叠加，程序会把贡献合并为一条带权重的单元。

本算例中的四个层间刚度分别采用不同表达方式：

| 变量 | 类型 | 恢复力处理 | 是否出现在 `System.eles` |
|---|---|---|---|
| `k1` | `Steel01` | 使用第一组双线性滞回参数 | 是 |
| `k2` | `Steel01` | 使用第二组双线性滞回参数，与 `k1` 状态独立 | 是 |
| `k3` | `Elastic` | 调用弹性材料接口计算 | 是 |
| `k4` | `float` | 作为普通数值刚度参与 `K_numeric @ u` | 否 |

因此最终生成三个可选择记录的单元。第四层数值刚度仍完整参与恢复力、初始刚度、模态分析和 Rayleigh 阻尼计算，但没有单独的材料运行实例，不能通过 `ele_force` 或 `ele_defo` 直接输出。若需要记录第四层响应，应把 `k4` 改为 `Elastic(tag=4, k=180.0)`。

### 2.6 模态与阻尼

对应 `main.py` 的第 6 个代码块：

```python
modal_system = System(
    mass=mass,
    damping=np.zeros_like(mass.values),
    stiffness=stiffness,
    load=load,
)

modal = modal_system.eigen(n_modes=4, influence=influence)
eigenvalues = modal.eigenvalues
omega = modal.circular_frequencies
frequencies = modal.frequencies
periods = modal.periods
shapes = modal.mode_shapes
participation = modal.participation_factors
effective_mass = modal.effective_modal_masses
effective_mass_ratio = modal.effective_modal_mass_ratios

omega1, omega2 = omega[:2]

damping_ratio = 0.05
a0 = 2.0 * damping_ratio * omega1 * omega2 / (omega1 + omega2)
a1 = 2.0 * damping_ratio / (omega1 + omega2)

damping = DampingMatrix(
    a0 * mass + a1 * modal_system.initial_stiffness()
)
```

Rayleigh 阻尼采用：

\[
C=a_0 M+a_1 K_0,
\]

其中 `K0` 是所有材料通过 `getInitialTangent()` 形成的初始刚度矩阵。第 `i` 阶模态阻尼比为：

\[
\zeta_i=\frac{a_0}{2\omega_i}+\frac{a_1\omega_i}{2}.
\]

当第 1、2 阶目标阻尼比均为 `ζ` 时，两项系数为：

\[
a_0=\frac{2\zeta\omega_1\omega_2}{\omega_1+\omega_2},
\qquad
a_1=\frac{2\zeta}{\omega_1+\omega_2}.
\]

代码变量与公式的对应关系：

| 变量 | 类型 | 含义 |
|---|---|---|
| `modal_system` | `System` | 用零阻尼建立的临时体系，只用于计算初始模态。阻尼不参与广义特征值问题。 |
| `modal` | `ModalResult` | 一次 `eigen(n_modes=4, influence=influence)` 调用返回的四阶模态结果。 |
| `omega1`, `omega2` | `numpy.float64` | 第 1、2 阶圆频率，必须是有限正数。 |
| `damping_ratio` | `float` | 两个选定模态共同采用的目标阻尼比；`0.05` 表示 5%。 |
| `a0` | `float` | 质量比例系数，量纲为 `1/s`。 |
| `a1` | `float` | 初始刚度比例系数，量纲为 `s`。 |
| `damping` | `DampingMatrix` | 最终用于时程分析的 Rayleigh 阻尼矩阵。 |

模态分析接口：

```python
modal_system.eigen(
    n_modes: int | None = None,
    influence: numpy.typing.ArrayLike | None = None,
) -> ModalResult
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `n_modes` | `int | None` | 需要计算的最低阶模态数量。本例为四自由度体系，因此使用 `4` 得到全部四阶模态。`None` 也表示返回全部模态。 |
| `influence` | `ArrayLike | None` | 可选影响向量。传入后额外计算模态参与系数、有效模态质量和有效模态质量比。本例直接使用地震惯性荷载中的 `influence`。 |

模态结果通过 `ModalResult` 的属性直接获取：

```python
eigenvalues = modal.eigenvalues
omega = modal.circular_frequencies
frequencies = modal.frequencies
periods = modal.periods
shapes = modal.mode_shapes
classification = modal.classification
participation = modal.participation_factors
effective_mass = modal.effective_modal_masses
effective_mass_ratio = modal.effective_modal_mass_ratios

first_shape = shapes[:, 0]
second_shape = shapes[:, 1]
```

| 属性 | 类型与形状 | 含义 |
|---|---|---|
| `eigenvalues` | `numpy.ndarray`，形状 `(n_modes,)` | 广义特征值 `λi`。对振动模态有 `λi=ωi²`。 |
| `circular_frequencies` | `numpy.ndarray`，形状 `(n_modes,)` | 圆频率 `ωi`，单位为 `rad/s`。刚体模态为 `0`，不稳定模态为 `NaN`。 |
| `frequencies` | `numpy.ndarray`，形状 `(n_modes,)` | 频率 `fi=ωi/(2π)`，单位为 `Hz`。 |
| `periods` | `numpy.ndarray`，形状 `(n_modes,)` | 周期 `Ti=2π/ωi`，单位为 `s`。刚体模态为无穷大，不稳定模态为 `NaN`。 |
| `mode_shapes` | `numpy.ndarray`，形状 `(n_dof, n_modes)` | 质量归一化振型矩阵。每一列是一阶振型，例如第一阶为 `mode_shapes[:, 0]`。 |
| `classification` | `tuple[str, ...]` | 各模态分类：`"vibration"`、`"rigid"` 或 `"unstable"`。 |
| `participation_factors` | `numpy.ndarray | None` | 模态参与系数。只有传入 `influence` 时才计算。 |
| `effective_modal_masses` | `numpy.ndarray | None` | 有效模态质量。只有传入 `influence` 时才计算。 |
| `effective_modal_mass_ratios` | `numpy.ndarray | None` | 有效模态质量占输入方向总质量的比例。只有传入 `influence` 时才计算。 |

本例的振型已经满足质量归一化条件：

\[
\phi_i^\mathsf{T}M\phi_j=\delta_{ij}.
\]

振型向量整体乘以 `-1` 仍表示同一模态，因此不同软件之间振型符号相反并不代表结果错误。

模态结果可以写入文件：

```python
modal.save_csv(path: str | pathlib.Path) -> None
modal.save_npz(path: str | pathlib.Path) -> None
```

CSV 每行对应一阶模态，包含特征值、圆频率、频率、周期、各自由度振型分量、参与系数、有效模态质量、质量比和模态分类。NPZ 保留这些数组及原始二维振型矩阵。

初始刚度查询接口：

```python
modal_system.initial_stiffness() -> numpy.ndarray
```

该方法返回有限的初始整体刚度矩阵，不改变材料状态。模态分析和 Rayleigh 刚度比例项必须使用这一公开结果，不能读取 `Steel01.k`、`ModTakeda.k0` 等材料内部字段。

如果第 1、2 阶目标阻尼比分别为 `zeta1` 和 `zeta2`，可以求解以下二元方程：

```python
coefficient_matrix = np.array([
    [1.0 / (2.0 * omega1), omega1 / 2.0],
    [1.0 / (2.0 * omega2), omega2 / 2.0],
])
a0, a1 = np.linalg.solve(
    coefficient_matrix,
    np.array([zeta1, zeta2]),
)
```

若选定模态属于刚体模态、不稳定模态，或者两个圆频率相同，不能用这两个模态唯一确定上述 Rayleigh 系数，应改选两个不同的正频率模态。

构造接口：

```python
DampingMatrix(values: numpy.typing.ArrayLike) -> DampingMatrix
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `values` | `ArrayLike` | 有限、对称的二维方阵。其阶数必须与质量和刚度矩阵相同。 |

常用属性和运算：

```python
damping.values: numpy.ndarray
damping.shape: tuple[int, int]

damping_a + damping_b -> DampingMatrix
damping_a - damping_b -> DampingMatrix
factor * damping -> DampingMatrix
```

质量和最终阻尼矩阵在一次时程分析过程中保持不变。Rayleigh 阻尼只保证两个选定模态达到指定阻尼比；其他模态的阻尼比由频率和上述公式共同决定。

### 2.8 分析配置

对应 `main.py` 的第 8 个代码块：

```python
integrator = Newmark(gamma=0.5, beta=0.25)

algorithms = (
    Newton(),
    NewtonLineSearch(),
    KrylovNewton(max_dimension=3),

convergence_test = NormUnbalance(norm_type=2)

analysis = TransientAnalysis(
    system=system,
    integrator=integrator,
    algorithms=algorithms,
    convergence_test=convergence_test,
    rtol=1e-6,
    atol=1e-8,
    max_iter=30,
)
```

#### 积分器接口

```python
Newmark(gamma: float = 0.5, beta: float = 0.25) -> Newmark
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `gamma` | `float` | 速度更新参数，必须大于 `0`。默认 `0.5`。 |
| `beta` | `float` | 位移更新参数，必须大于 `0`。默认 `0.25`。 |

默认参数对应平均加速度法。

```python
HHT(
    alpha: float = 0.9,
    gamma: float | None = None,
    beta: float | None = None,
) -> HHT
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `alpha` | `float` | OpenSees 正参数约定，范围为 `[2/3, 1]`。越小，高频数值耗散越强；`1` 退化为 Newmark。 |
| `gamma` | `float | None` | 速度参数。`None` 时采用 `1.5-alpha`。 |
| `beta` | `float | None` | 位移参数。`None` 时采用 `(2-alpha)^2/4`。 |

HHT 在加权中间状态评价平衡，收敛后在完整步末状态重新计算并提交材料。

```python
CentralDifference() -> CentralDifference
```

中心差分法没有构造参数。它采用固定步长显式推进，不进行非线性迭代、缩步或算法切换。分析终点和固定记录间隔都必须位于计算步长网格上。使用中心差分法时，`algorithms` 和 `convergence_test` 不参与推进。

#### 非线性算法接口

```python
Linear() -> Linear
Newton() -> Newton
```

`Linear` 只执行一次线性修正，适用于纯数值刚度或全部采用 `Elastic` 的隐式体系。非线性隐式体系不能把 `Linear` 放入候选算法。`Newton` 在每次外层迭代重新组装当前有效刚度。

```python
NewtonLineSearch(
    tolerance: float = 0.8,
    max_search_iter: int = 10,
    min_eta: float = 0.1,
    max_eta: float = 10.0,
) -> NewtonLineSearch
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `tolerance` | `float` | 线搜索方向函数相对初值的接受容差。 |
| `max_search_iter` | `int` | 每次外层 Newton 修正允许的最大线搜索次数。 |
| `min_eta` | `float` | 位移修正倍率 `eta` 的下限。 |
| `max_eta` | `float` | 位移修正倍率 `eta` 的上限。 |

```python
KrylovNewton(max_dimension: int = 3) -> KrylovNewton
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `max_dimension` | `int` | Krylov 加速子空间最大维数，必须大于 `0`。达到上限或出现秩退化时重启子空间。 |

#### 收敛检验接口

```python
NormUnbalance(norm_type: float = 2.0) -> NormUnbalance
NormDispIncr(norm_type: float = 2.0) -> NormDispIncr
EnergyIncr() -> EnergyIncr
```

设 `R` 为施加本次修正后重新组装的不平衡力，`Δu` 为本次实际施加的位移修正：

| 类 | 检验值 | 适用说明 |
|---|---|---|
| `NormUnbalance` | `||R||p` | 直接检查动力平衡，通常作为首选。 |
| `NormDispIncr` | `||Δu||p` | 检查迭代位移是否已足够小。体系病态或使用很大罚刚度时，应同时关注力残差。 |
| `EnergyIncr` | `0.5*abs(Δu.T@R)` | 同时考虑位移修正和不平衡力。两向量近似正交时检验值可能较小。 |

`norm_type` 是 NumPy 范数阶数，常用值为 `1`、`2` 和 `np.inf`。`EnergyIncr` 不需要该参数。

三个检验统一采用：

\[
\text{test value}\leq \text{atol}+\text{rtol}\,s.
\]

- `NormUnbalance` 的 `s` 是荷载、惯性力、阻尼力和恢复力范数的最大值，且不小于 `1`。
- `NormDispIncr` 的 `s` 是 `max(1, ||u||p)`。
- `EnergyIncr` 的 `s` 是 `max(1, 0.5*||u||2*s_force)`。

若要采用与 OpenSees 对应检验相同的纯绝对容差形式，应设置 `rtol=0`，此时 `atol` 相当于 OpenSees 的 `tol`。

#### TransientAnalysis 构造接口

```python
TransientAnalysis(
    system: System,
    integrator: Newmark | HHT | CentralDifference = Newmark(),
    algorithms: tuple[SolutionAlgorithm, ...] = (
        Newton(),
        NewtonLineSearch(),
        KrylovNewton(),
    ),
    rtol: float = 1e-6,
    atol: float = 1e-8,
    max_iter: int = 30,
    convergence_test: ConvergenceTest = NormUnbalance(),
    min_factor: float = 1e-6,
    shrink_factor: float = 0.5,
    growth_factor: float = 2.0,
    growth_after: int = 2,
) -> TransientAnalysis
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `system` | `System` | 已完成矩阵、荷载和材料检查的动力体系。 |
| `integrator` | `Newmark | HHT | CentralDifference` | 时程积分方法。 |
| `algorithms` | `tuple[SolutionAlgorithm, ...]` | 隐式分析的候选算法，按元组顺序尝试；不能为空。 |
| `rtol` | `float` | 所选收敛检验的相对容差，必须不小于 `0`。 |
| `atol` | `float` | 所选收敛检验的绝对容差，必须不小于 `0`。 |
| `max_iter` | `int` | 每个算法在一次步长尝试中的最大外层迭代次数，必须大于 `0`。 |
| `convergence_test` | `ConvergenceTest` | `NormUnbalance`、`NormDispIncr` 或 `EnergyIncr` 实例。 |
| `min_factor` | `float` | 最小步长与传给 `run()` 的初始步长之比，范围 `(0, 1]`。 |
| `shrink_factor` | `float` | 失败后步长倍率，范围 `(0, 1)`。 |
| `growth_factor` | `float` | 满足恢复条件后的步长放大倍率，必须大于 `1`。 |
| `growth_after` | `int` | 连续成功多少步后尝试放大步长，必须大于 `0`。 |

响应选择参数：

| 参数 | 类型 | 含义 |
|---|---|---|
| `disp` | `list[int] | tuple[int, ...] | "all" | None` | 节点位移自由度。`"all"` 选择全部；整数序列选择指定自由度；`None` 不记录。 |
| `velo` | `list[int] | tuple[int, ...] | "all" | None` | 节点速度自由度，选择规则同 `disp`。 |

| `ele_force` | `list[str] | tuple[str, ...] | "all" | None` | 单元内力。字符串必须来自 `System.eles` 的 `id`。 |
| `ele_defo` | `list[str] | tuple[str, ...] | "all" | None` | 单元变形，编号规则同 `ele_force`。 |

`mode` 的三个值含义如下：

| `mode` 值 | `result.responses` 与 `result.times` | `result.peaks` | 适用场景 |
|---|---|---|---|
| `"history"` | 保存所选响应时程 | 空字典 | 需要绘制或后处理完整响应过程。 |
| `"peak"` | 不在内存中保存时程，`times` 为空数组 | 保存正峰、负峰和绝对值峰值及对应时刻 | 只关心包络结果，希望降低内存使用。 |
| `"both"` | 保存所选响应时程 | 同时保存全部峰值信息 | 同时需要过程曲线和包络。 |

其他参数：

| 参数 | 类型 | 含义 |
|---|---|---|
| `diagnostics` | `bool` | 为 `True` 时保存每次接受或拒绝尝试的步长、算法、迭代次数、力残差、收敛检验值和原因。 |
| `csv_path` | `str | Path | None` | CSV 输出路径。设置后在分析过程中逐行写入所选时程，列名使用 `disp[0]`、`ele_force[E1]` 等简写。 |

CSV 流式输出与内存 `mode` 相互独立：只要设置 `csv_path`，所选响应就会按记录时刻写入文件。这样可以使用 `mode="peak"`、`keep_in_memory=False`，在内存中只保留峰值，同时把时程写入 CSV。

运行接口：

```python
analysis.run(
    dt: float,
    t_end: float | None = None,
    *,
    t_start: float | None = None,
    u0: numpy.typing.ArrayLike | None = None,
    v0: numpy.typing.ArrayLike | None = None,
    recorder: Recorder | None = None,
) -> AnalysisResult
```

| 参数 | 类型 | 含义 |
|---|---|---|
| `dt` | `float` | 初始分析步长，必须大于 `0`。隐式分析失败后可能自动缩小。 |
| `t_end` | `float | None` | 分析终止时刻。`None` 表示采用荷载的 `t_max`。 |
| `t_start` | `float | None` | 分析起始时刻。`None` 表示采用荷载的 `t_min`。 |
| `u0` | `ArrayLike | None` | 初始位移向量。`None` 表示全零；长度必须等于 `ndof`。非零值按材料从初始状态加载到该变形解释。 |
| `v0` | `ArrayLike | None` | 初始速度向量。`None` 表示全零；长度必须等于 `ndof`。 |
| `recorder` | `Recorder | None` | 输出设置。`None` 表示不保存响应，但分析仍会执行。 |

初始加速度由动力平衡自动求解：

\[
\ddot u_0=M^{-1}\left[p(t_0)-C\dot u_0-f_{\mathrm{int}}(u_0)\right].
\]

隐式分析的自适应顺序为：

1. 使用当前候选算法和当前步长试算。
2. 失败时完整恢复材料状态，并把步长乘以 `shrink_factor`。
3. 一直缩小到 `dt*min_factor`。
4. 最小步长仍失败时，切换到下一个候选算法。
5. 连续成功 `growth_after` 步后，把步长乘以 `growth_factor`，但不超过初始 `dt`。
6. 每个初始 `dt` 对应的基准区间开始时重新优先使用第一个算法。

| `peaks` | `dict[str, dict[int | str, Peak]]` | `mode="peak"` 或 `"both"` 时的峰值结果。 |
| `diagnostics` | `list[dict[str, float | int | str]]` | 开启诊断后的步长尝试记录。 |

## 三、常见错误与排查方法

### 3.1 输入矩阵错误

| 错误信息或现象 | 常见原因 | 处理方法 |
|---|---|---|
| 质量矩阵必须是方阵 | 输入是一维质量列表或行列数不同 | 对集中质量使用 `np.diag(masses)`；检查数组形状。 |
| 质量矩阵必须对称 | 对称位置数值不同 | 检查单位、索引和矩阵组装过程。 |
| 质量矩阵必须正定 | 存在零质量、负质量或未消除的约束自由度 | 在输入求解器前消除这些自由度，或建立正定的一致质量矩阵。 |
| 阻尼矩阵必须对称 | 阻尼组装不对称 | 修正对应位置，使 `C == C.T`。 |
| 自由度数必须一致 | 四个输入对象阶数不同 | 检查 `mass.shape`、`damping.shape`、`stiffness.shape` 和 `load.size`。 |

### 3.2 刚度表达式和材料错误

| 错误信息或现象 | 常见原因 | 处理方法 |
|---|---|---|
| 材料 tag 必须是整数 | 使用了字符串、浮点数或布尔值 | 使用 `tag=1` 这类整数。 |
| 材料 tag 在同一体系中重复 | 两个不同模板使用了相同 tag | 为每个模板分配唯一整数 tag。 |
| 材料系数矩阵不对称 | 对角项或负非对角项填写不完整 | 按标准弹簧矩阵同时填写四个对应项。 |
| 非对角系数必须非正 | 把两自由度连接的耦合项写成正数 | 对连接 `i-j` 使用 `K[i,j]=K[j,i]=-mat`。 |
| 材料系数矩阵行和不能为负 | 对角贡献小于连接贡献 | 检查对地项和层间项的叠加。 |
| 材料缺少接口 | 自定义材料没有完整实现公共方法 | 按第四章实现全部材料接口。 |
| 材料返回非有限值 | 参数、除零、非法幂运算或状态更新异常 | 单独加载材料，检查每一步的应力和切线。 |

纯数值刚度不会生成 `System.eles` 中的可记录单元。若需要单独输出某个弹性连接的内力或变形，应使用 `Elastic(tag, k)` 填入刚度矩阵。

### 3.3 荷载和时间范围错误

| 错误信息或现象 | 常见原因 | 处理方法 |
|---|---|---|
| 荷载数组形状错误 | 传入一维数组或转置了时间轴和自由度轴 | 使用形状 `(n_time, n_dof)`。 |
| 等步长荷载缺少 dt | 构造数组荷载时没有给采样间隔 | 使用 `LoadHistory(samples, dt=dt)`。 |
| 荷载查询时间超出范围 | `t_start` 或 `t_end` 超出样本时段 | 将分析范围限制在 `[load.t_min, load.t_max]`。 |
| 函数荷载返回错误形状 | 回调返回标量、二维数组或长度变化 | 始终返回形状 `(size,)` 的有限向量。 |
| 中心差分终点不在网格 | `(t_end-t_start)/dt` 不是整数 | 调整 `dt` 或终止时刻。 |

### 3.4 记录器错误

| 错误信息或现象 | 常见原因 | 处理方法 |
|---|---|---|
| 节点记录索引无效或重复 | 自由度越界、负索引或重复选择 | 使用 `0 <= dof < system.ndof` 的唯一索引。 |
| 单元记录编号无效或重复 | 编号不在 `System.eles` 中 | 先打印 `system.eles`，再选择其中的 `id`。 |
| mode 无效 | 使用了 `"peaks"` 或其他字符串 | 只使用 `"history"`、`"peak"`、`"both"`。 |
| keep_in_memory=False 时缺少 csv_path | 不保留内存时程，又没有文件目标 | 提供 CSV 路径。 |
| 结果属性出现 KeyError | 没有选择该响应，或 `mode="peak"` 不保存时程 | 检查 Recorder 选择；峰值模式从 `result.peaks` 读取。 |

### 3.5 不收敛和异常响应

出现不收敛时，建议设置：

```python
recorder = Recorder(
    disp="all",
    mode="both",
    diagnostics=True,
)
```

每条隐式诊断通常包含：

| 键 | 类型 | 含义 |
|---|---|---|
| `time` | `float` | 接受步的终点；拒绝步为当前已提交时刻。 |
| `dt` | `float` | 本次尝试步长。 |
| `algorithm` | `str` | 使用的算法名称。 |
| `iterations` | `int` | 外层迭代次数。 |
| `residual` | `float` | 最终不平衡力二范数。 |
| `test` | `str` | 收敛检验名称。 |
| `test_value` | `float` | 本次检验值。 |
| `test_limit` | `float` | 本次允许上限。 |
| `status` | `str` | `"accepted"` 或 `"rejected"`。 |
| `reason` | `str` | 拒绝原因；接受步通常没有该键。 |

排查顺序：

1. 检查单位制和矩阵量级。
2. 检查材料单独加载时的恢复力、切线、提交和回退。
3. 查看失败是否只发生在荷载突变、屈服或反向加载附近。
4. 减小初始 `dt`，或适当调整 `min_factor`。
5. 把 `NewtonLineSearch()` 和 `KrylovNewton()` 加入候选算法。
6. 收紧或放宽容差时，同时检查结果是否具有足够精度。
7. 若 `NormDispIncr` 或 `EnergyIncr` 已通过而力残差仍很大，改用 `NormUnbalance`。

中心差分结果发散或高频振荡通常属于稳定性问题。应减小固定步长，并用 `system.central_difference_limit()` 作为初步参考。

## 四、扩展新的非线性材料

### 4.1 必须实现的公共接口

新材料应继承 `UniaxialMaterial`，并提供唯一整数 `tag`。求解器只通过以下公开方法访问材料：

```python
class UniaxialMaterial:
    tag: int

    def setTrialStrain(
        self,
        strain: float,
        strainRate: float = 0.0,
    ) -> None: ...

    def getStrain(self) -> float: ...
    def getStress(self) -> float: ...
    def getTangent(self) -> float: ...
    def getInitialTangent(self) -> float: ...
    def commitState(self) -> None: ...
    def revertToLastCommit(self) -> None: ...
    def revertToStart(self) -> None: ...
    def getCopy(self) -> UniaxialMaterial: ...
```

各接口契约：

| 接口 | 参数与返回类型 | 必须满足的行为 |
|---|---|---|
| `setTrialStrain` | `strain: float`, `strainRate: float = 0.0`，返回 `None` | 从最近一次提交状态出发，计算指定试算变形下的试算状态。重复调用不能永久修改提交历史。 |
| `getStrain` | 返回 `float` | 返回当前试算变形。 |
| `getStress` | 返回 `float` | 返回当前试算内力。名称沿用单轴材料约定，在本程序中作为连接力使用。 |
| `getTangent` | 返回 `float` | 返回当前试算状态用于非线性平衡迭代的切线或材料规定的近似切线。必须有限。 |
| `getInitialTangent` | 返回 `float` | 返回材料初始刚度。该值用于初始刚度组装和模态分析，不应随加载历史变化。 |
| `commitState` | 返回 `None` | 把当前试算状态接受为新的提交状态。 |
| `revertToLastCommit` | 返回 `None` | 用最近提交状态覆盖试算状态，不改变提交历史。 |
| `revertToStart` | 返回 `None` | 恢复到新建材料的初始状态。 |
| `getCopy` | 返回独立的 `UniaxialMaterial` | 返回参数、试算状态和提交状态均独立的副本。修改副本不能改变模板或其他副本。 |

求解器不会读取 `k`、`k0`、屈服变量或其他内部字段。初始刚度只能通过 `getInitialTangent()` 提供。

### 4.2 试算状态和提交状态

非线性迭代可能在同一时间步反复尝试多个变形，也可能因为缩步或切换算法而放弃整个尝试。因此材料至少需要区分：

- 提交状态：最近一个成功时间步的历史。
- 试算状态：当前迭代点临时计算出的响应。

推荐的调用逻辑是：

```text
revertToLastCommit()
setTrialStrain(q_trial)
getStress() / getTangent()
        ↓
若时间步成功：commitState()
若时间步失败：revertToLastCommit()
```

`setTrialStrain()` 应确保每次试算都从最近提交状态重算。它不能把上一次未提交试算的峰值、方向或损伤直接带入下一次试算。

`getCopy()` 是材料模板复用的基础。刚度矩阵中的一个模板可能生成多条不同连接，每条连接必须拥有独立副本和独立加载历史。

### 4.3 最小材料示例

下面给出一个只用于说明接口的线性材料。实际非线性模型可以在同样结构中增加屈服、卸载、损伤和循环历史变量。

```python
from __future__ import annotations

from numbers import Integral

from mdof_solver.materials import UniaxialMaterial


class UserElastic(UniaxialMaterial):
    def __init__(self, tag: int, stiffness: float):
        if isinstance(tag, bool) or not isinstance(tag, Integral):
            raise TypeError("材料 tag 必须是整数")
        if stiffness <= 0:
            raise ValueError("stiffness 必须大于 0")
        self.tag = int(tag)
        self._stiffness = float(stiffness)
        self.revertToStart()

    def setTrialStrain(
        self,
        strain: float,
        strainRate: float = 0.0,
    ) -> None:
        self.revertToLastCommit()
        self._trial_strain = float(strain)
        self._trial_stress = self._stiffness * self._trial_strain

    def getStrain(self) -> float:
        return self._trial_strain

    def getStress(self) -> float:
        return self._trial_stress

    def getTangent(self) -> float:
        return self._stiffness

    def getInitialTangent(self) -> float:
        return self._stiffness

    def commitState(self) -> None:
        self._commit_strain = self._trial_strain
        self._commit_stress = self._trial_stress

    def revertToLastCommit(self) -> None:
        self._trial_strain = self._commit_strain
        self._trial_stress = self._commit_stress

    def revertToStart(self) -> None:
        self._commit_strain = 0.0
        self._commit_stress = 0.0
        self._trial_strain = 0.0
        self._trial_stress = 0.0

    def getCopy(self) -> UserElastic:
        copied = UserElastic(self.tag, self._stiffness)
        copied._commit_strain = self._commit_strain
        copied._commit_stress = self._commit_stress
        copied._trial_strain = self._trial_strain
        copied._trial_stress = self._trial_stress
        return copied
```

定义完成后无需注册材料类型，可以像内置材料一样放入刚度矩阵：

```python
mat = UserElastic(tag=20, stiffness=100.0)
stiffness = StiffnessMatrix([[mat]])
```

### 4.4 新材料验证建议

在用于完整时程分析前，建议至少验证：

1. 新建材料的 `getStrain()` 和 `getStress()` 返回零，`getTangent()` 与 `getInitialTangent()` 返回正确初始刚度。
2. 单调加载下的屈服点、峰值点和屈服后刚度符合公式。
3. 卸载、反向加载和再加载路径符合预期。
4. 对同一提交状态反复调用不同 `setTrialStrain()`，结果只取决于提交历史和当前输入。
5. `revertToLastCommit()` 能完全清除未提交试算的影响。
6. `commitState()` 后再次回退能恢复到刚提交的状态。
7. `revertToStart()` 与新建材料状态一致。
8. `getCopy()` 返回的副本与原对象互不影响。
9. `getInitialTangent()` 在经历任意加载历史后仍保持不变。
10. 在光滑分支内部，用有限差分检查 `getTangent()` 是否与恢复力局部导数一致；若返回割线或其他近似切线，应明确其收敛特性。
11. 把同一模板放在两个不同变形映射中，确认一条连接加载或屈服不会改变另一条连接的材料状态。

材料响应验证通过后，再用单自由度和小型多自由度模型检查时程收敛、缩步回退、算法切换和结果记录。
